# 美東 祭り資金造成 ポータブル会計・管理アプリ (Bito POS)

地域の祭りやイベントでの部活動資金造成を強力に支援する、**完全オフライン対応・スマホ片手操作特化型のPWA（Progressive Web App）**です。

---

## 🌟 主な特徴と提供機能

1. **📱 スマホ片手操作に最適化したレジUI**
   - 屋外の強い日差しの下でもクッキリ見える高コントラスト・大型ボタンデザイン。
   - タップで即カート追加、合計金額・点数を自動計算。
   - お預かり金額のワンタップ入力（「ぴったり」「+1,000円」「+2,000円」「+5,000円」など）とお釣り自動計算。
   - メイン担当2名、モバイル販売担当（歩き売り）2名に対応した瞬時の担当者切り替え。

2. **⚡ 完全オフライン動作 & 自動バックグラウンド同期**
   - **Service Worker:** 一度読み込めば圏外・電波切断状態でも完全にアプリが起動・稼働。
   - **IndexedDB:** 会計データ・在庫データを端末ローカルに安全保存。電波がなくても売上登録と在庫減算が途切れません。
   - **GAS (Google Apps Script):** 電波復帰時にバックグラウンドでGoogleスプレッドシートへ自動同期。重複防止（冪等性）と同時書き込みロックを完備。
   - 画面上部に「🟢 オンライン」「🟡 オフライン」「🔄 同期中」および「未同期件数バッジ」を常時表示。

3. **📦 商品・在庫管理（項目の追加・編集・削除）**
   - **新規商品の登録:** 商品名・販売価格・初期準備数をアプリからいつでも追加可能。
   - **商品情報の編集:** 「✏️ 編集」ボタンから、商品名、販売価格、現在庫数、初期準備数を自由に修正可能。
   - **商品の削除:** 不要になった商品を「🗑️ 削除」ボタンから確認ダイアログ付きで安全に削除（レジ画面や集計からも自動連動で除外）。
   - **在庫クイック補充:** 在庫一覧から「+10」「+50」ボタンでワンタップ補充。
   - **完売制御:** 在庫0で自動的に「完売（売り切れ）」表示＆タップ無効化。

4. **📊 売上ダッシュボード & グラフ分析**
   - 本日総売上、会計客数、販売総個数、平均客単価のリアルタイムKPIカード。
   - 時間帯別の売上推移グラフ（1時間単位の棒グラフ）。
   - 商品別の売上シェアランキング。
   - 担当者別（メインテント vs 歩き売り）の販売実績比較。

5. **📥 Excel対応 CSVデータ出力 (UTF-8 BOM付き)**
   - 「売上明細 CSV」
   - 「商品別集計 CSV」
   - 「時間帯別集計 CSV」
   - ※文字化け防止のBOM付きUTF-8形式を採用しており、Excelでそのまま開けます。

## 🚀 クイックスタート (ローカル確認)

Node.jsがインストールされている環境であれば、外部パッケージのインストール不要で即座に起動できます。

```bash
# サーバー起動 (ポート 3000)
node server.js
```

ブラウザで `http://localhost:3000` を開くと、アプリの全機能（レジ、在庫管理、ダッシュボード、モックAPI同期、CSV出力）が動作します。

```bash
# 全体テストの実行
node test/test-all.js
```

## 📱 本番運用手順 (Googleスプレッドシート連携 ＆ スマホ利用)

### ステップ 1: スプレッドシートとGASのデプロイ
1. [Google スプレッドシート](https://sheets.new) を新規作成します。
2. メニューの **「拡張機能」>「Apps Script」** を開きます。
3. `gas/Code.gs` の内容を貼り付けて保存します。
4. 実行関数で **`initSpreadsheet`** を選択して「実行」をクリックします（`Products`シートと`Sales`シートが初期データ入りで自動生成されます）。
5. 右上の **「デプロイ」>「新しいデプロイ」** を選び、「種類: ウェブアプリ」「アクセスできるユーザー: **全員**」でデプロイします。
6. 発行された **「ウェブアプリのURL」** をコピーします。
*(詳細は [gas/README_GAS.md](file:///c:/Users/Jay.T/OneDrive/デスクトップ/美東　資金造成会計アプリ/gas/README_GAS.md) を参照)*

### ステップ 2: アプリのホスティング（無料公開）
以下のいずれかの方法で静的ファイル（本リポジトリ全体）を公開します：
- **GitHub Pages:** リポジトリを作成してプッシュし、Settings > Pages から「main branch」を選択するだけで即座にHTTPSで公開されます。
- **Cloudflare Pages / Netlify / Vercel:** フォルダをドラッグ＆ドロップするだけで即座に公開されます。

### ステップ 3: スマホへのインストール（PWA追加）
1. スマートフォンのブラウザ（iPhone: Safari / Android: Chrome）で公開URLを開きます。
2. **GAS Web App URLはソースコードに事前設定済み**のため、URLの入力作業は不要です。アプリを開いた瞬間から自動的にスプレッドシートと連動します。
3. **ホーム画面に追加:**
   - **iPhone (Safari):** 画面下の共有ボタン ⎋ > **「ホーム画面に追加」**
   - **Android (Chrome):** メニュー ⋮ > **「ホーム画面に追加」** または **「アプリをインストール」**
4. ホーム画面に専用アプリアイコンが追加され、全画面アプリとしてオフラインでも快適に起動できます！

## 🎪 祭り当日の運用マニュアル

1. **担当者の役割分担**
   - **メイン担当1・2（テント内）:** 屋台の固定レジとして、画面上部の担当者を「メイン担当1」「メイン担当2」に設定。
   - **モバイル販売1・2（歩き売り）:** スマホを持って会場内を巡回し、担当者を「モバイル販売1(歩き)」「モバイル販売2(歩き)」に設定。

2. **電波が切れた・不安定な場合**
   - 何も心配いりません。アプリ上部に「🟡 オフライン(ローカル保存)」と表示され、通常通り商品タップ・会計が続けられます。
   - 未同期の売上件数がバッジで蓄積されます。
   - 電波が復帰するかWi-Fiに接続した時点で、自動的にバックグラウンドでスプレッドシートへ安全に送信されます（「設定」タブの「今すぐ同期」を押してもOK）。

3. **イベント終了後の集計**
   - 全端末の未同期件数が0になっていることを確認します。
   - 「📊 売上分析」タブを開き、**「売上明細 CSV」「商品別集計 CSV」** をタップしてダウンロードします。
   - Excelでそのまま開き、部活動の会計報告書作成にご活用いただけます。
